We used code (Python) to build a machine learning model to predict future solar energy output in Cambridge, Minnesota based on historical solar and weather data. (See graphs below for the preliminary data collected from June 2024 until February  predicted output)  The model focuses on selected months of the year, trains a Random Forest Regressor, and uses the model to forecast energy production from 2025 to 2045, accounting for yearly performance degradation. The results are visualized with a line plot showing trends over time for each month, along with a detailed table summarizing predicted monthly and yearly outputs.​
